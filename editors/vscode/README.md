# mdprompt

`.mdp`와 `.mdprompt` 파일의 GFM, `$`/`$$` TeX 수식, `^% … %^` 인라인 AI 지시와 단독 줄의 `^%%` / `%%^` 블록 AI 지시를 강조합니다.

**mdprompt: Preview document content** 명령을 사용하려면 `mdprompt-cli`를 PATH에 추가하거나 VS Code를 시작하기 전에 `MDPROMPT_NATIVE`를 지정해야 합니다. 미리보기는 이스케이프한 TeX 마크업을 표시하며 수식 시각 렌더러는 포함하지 않습니다.  

코드 블록 본문에는 에디터 기본 글자색을 적용합니다. 내부의 `^%` 구간도 같은
색으로 표시하며, 블록 바깥의 지시 하이라이트는 유지합니다. 문서를 편집하거나
다른 편집기로 전환하면 색상 범위를 다시 계산합니다.
